## Motivation

Why this project exists:  

- I wanted to practice data visualization — turning raw data into clear, compelling stories.  
- The Seaborn library in Python makes it easy to draw elegant statistical plots. ([datacamp.com](https://www.datacamp.com/tutorial/seaborn-python-tutorial?utm_source=chatgpt.com))  
- The classic Tips dataset is perfect: simple enough to understand quickly, but rich enough to illustrate interesting patterns.  

In short: I treat each plot as a small investigative chapter, exploring how everyday choices (smoker status, party size, day/night, etc.) link to tipping behaviour.
